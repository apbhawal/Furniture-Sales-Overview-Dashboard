# 📊 Furniture Sales Overview Dashboard
> **Personal Skill Development Project | Microsoft Excel | Data Analytics Portfolio**

An interactive **Furniture Sales Overview Dashboard** built in **Microsoft Excel** to analyze sales performance, profitability, shipping trends, and regional distribution through KPI-driven visualizations and interactive reporting.

---

## 📌 About the Project

This is a **personal skill development project** created to strengthen my practical skills in **Microsoft Excel** and **Data Analytics** through hands-on dashboard development.

The project transforms raw furniture sales data into an interactive business dashboard that helps users monitor key sales metrics, identify trends, compare regional performance, and gain meaningful business insights using Excel's analytical features.
